Политика конфиденциальности

Приложение «Киллер Судоку — суммы» · пакет com.calculatorplatform.killersudoku

Разработчик: ForestMusic · forest-music.ru

Какие данные хранятся локально

Игровые сохранения, статистика, прогресс обучения, задача дня и настройки хранятся на устройстве пользователя. Резервная копия создаётся только по явному действию пользователя и сохраняется им самостоятельно.

Аналитика

Приложение использует Яндекс AppMetrica для событий использования (например, старт/завершение партии, Daily, обучение, подсказки, backup). В аналитику не передаются решение головоломки, содержимое заметок, состояние доски и содержимое резервных копий.

Реклама

Приложение использует Яндекс Mobile Ads для показа рекламных блоков (баннеры и межстраничная реклама после завершения обычной партии согласно внутриигровой политике).

Offline

Основной игровой процесс работает без сети. Сбой рекламы или аналитики не блокирует игру, Daily, обучение и сохранение прогресса.
